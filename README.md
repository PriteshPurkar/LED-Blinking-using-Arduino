# LED Blinking using Arduino

A beginner embedded systems project that blinks an LED using an Arduino Uno.

## Hardware Required
- Arduino Uno
- 1x LED (or use built-in LED on pin 13)
- 220Ω resistor
- Breadboard + jumper wires

## How to Run
1. Open `LED_Blink.ino` in Arduino IDE
2. Select Board: Arduino Uno
3. Select correct COM port
4. Click Upload

## Expected Output
LED blinks ON/OFF every 1 second.
